# Tanya Bas — personal website

Public website for Tanya Bas, AI safety researcher.

**Website:** https://tanya-bas.github.io/

## Pages

- Home: introduction, profile links, and public news updates.
- Research: selected publications.
- Writing: public notes and essays.

## Preview locally

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000. No dependencies or build step are required.

## Editing and publishing

See [DEVELOPMENT.md](DEVELOPMENT.md) for content editing instructions. GitHub Pages publishes the root of the `main` branch. Pushing a commit to `main` updates the public site.

This repository contains only the public website. It contains no private journal or login system.
